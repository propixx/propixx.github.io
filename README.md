# Pratyush Biswal — Portfolio

Live portfolio: https://propixx.github.io/

A responsive, buildless personal portfolio. Open `index.html`, or serve this repository with a static HTTP server. No framework, install step, API keys, account system, analytics, or backend required.

## Edit content

- `index.html`: profile, introduction, experience, education, skills, contact.
- `app.js`: nine projects, case studies, illustrations, filters and navigation.
- `style.css`: layout, palette, type and responsive breakpoints.
- `assets/Pratyush-Biswal-Resume.pdf`: the supplied one-page resume (September 2026 version).

The pages support direct URLs: `#overview`, `#projects`, `#experience`, and `#contact`.

## Design references and attribution

Student portfolio research included:

- Devansh Verma, whose portfolio describes him as a final-year IIT Kanpur student: https://devanshv17.github.io/ and https://github.com/Devanshv17/devanshv17.github.io
- Subodh Kasaudhan, IIT Kanpur alumnus (2020–2024): https://subodh-kasaudhan.github.io/Portfolio/ and https://github.com/subodh-kasaudhan/Portfolio

The vCard profile-sidebar, section-navigation, and project-filter patterns were adapted into a new visual implementation. Original template: https://github.com/codewithsadee/vcard-personal-portfolio (MIT). Its license is retained in `THIRD_PARTY_NOTICES.txt`. No personal photos, project claims, or biographical text were copied from the student reference sites.

Project visuals are original schematic SVG illustrations, not screenshots of deployed applications. Fonts are requested from Google Fonts with system-font fallbacks. All project and contact destinations come from the supplied resumes or verified public repositories. Figures distinguish validation from test results, model experiments from general claims, and completed work from planned features.

## Hosting

Hosted free on GitHub Pages at https://propixx.github.io/. Changes pushed to the publishing branch are automatically deployed. `.nojekyll` serves the files directly without a Jekyll build.
